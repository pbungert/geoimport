Geoimport

GPX extension, version 1

Namespace https://pbungert.github.io/geoimport/gpx/1

Tracks recorded by Geoimport are plain GPX 1.1. Each track point also carries what the receiver reported about its own fix, so a later pass can judge the track from the file alone.

The elements sit in the point's <extensions>. Readers that do not know the namespace skip them, and the track stays valid GPX. Each element is optional and left out when the receiver did not report it.

Elements

  • acc: horizontal accuracy in metres. It's the radius within which the true position lies with 68% probability.
  • eleacc: vertical accuracy of <ele> in metres, including the error of the sea-level model.
  • speed: speed over ground in metres per second. It's not GPX 1.0's <speed>, which is why it lives here.
  • src: where the fix came from: gps for satellite positioning, or fused for the phone's combined location from satellites, Wi-Fi and cell towers.

Example

<gpx version="1.1" creator="Geoimport"
     xmlns="http://www.topografix.com/GPX/1/1"
     xmlns:geoimport="https://pbungert.github.io/geoimport/gpx/1">
 <trk><trkseg>
  <trkpt lat="46.6863481" lon="7.8632150">
   <ele>566.3</ele>
   <time>2026-09-20T09:14:02Z</time>
   <extensions>
    <geoimport:acc>4.2</geoimport:acc>
    <geoimport:eleacc>6.1</geoimport:eleacc>
    <geoimport:speed>1.35</geoimport:speed>
    <geoimport:src>gps</geoimport:src>
   </extensions>
  </trkpt>
 </trkseg></trk>
</gpx>
